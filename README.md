# AIkafedra — система учёта нагрузки кафедры ИИ

Информационная система для **кафедры искусственного интеллекта**: учёт преподавателей и дисциплин, распределение учебной нагрузки по видам занятий и семестрам, отчёты о перегрузках и недогрузках, встроенный ИИ-ассистент на актуальных данных кафедры.

Проект реализован на Flask + SQLite, интерфейс на русском и казахском языках.

---

## Возможности

- 👤 **Преподаватели** — карточки, должность, ставка (0.25 … 1.5), лимиты нагрузки
- 📚 **Дисциплины** — справочник предметов кафедры с посевом из Excel/JSON
- 🧮 **Нагрузка** — распределение по видам занятий (лекции / практика / лабораторные / жетекші) и семестрам, учёт в **кредитах** согласно П ЕНУ K.V.14-22 (1 кр. = 15 ак. ч.)
- 📊 **Отчёты** — перегрузки и недогрузки, выгрузка в Excel
- 🤖 **ИИ-ассистент (Groq)** — вопросы по данным кафедры, поиск преподавателя, предсказание нагрузки
- 🔐 **Аутентификация** — Flask-Login, роли (администратор / преподаватель)
- 🌐 **Локализация RU / KZ** — переключение языка в один клик

## Стек

| Компонент | Технология |
|-----------|------------|
| Backend | Python 3.10+, Flask 3, Flask-Login |
| БД | SQLite (`workload.db`) |
| ИИ | Groq API (`llama-3.3-70b-versatile` по умолчанию) |
| Frontend | Jinja2, HTML/CSS/JS без фреймворков |
| Экспорт | openpyxl, xlrd, pypdf |
| Прод-сервер | gunicorn |

## Должности и нормы нагрузки

Согласно **П ЕНУ K.V.14-22 (Приложение 3)**:

| Должность | Макс. нагрузка (кр./ставку) |
|-----------|-----------------------------|
| Заведующий кафедрой (доцент) | 24 |
| Профессор / Доцент / Ст. преп. / Преподаватель / Ассистент | 30 |
| Преподаватель-исследователь | 15 |
| Исследователь | 8 (только жетекші) |

При ставке 1,5 максимум = `норма × 1.5` (например, 45 кр. для ППС).

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/MirasDavletaly/AIkafedra.git
cd AIkafedra
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Настроить переменные окружения

Создайте файл `.env` в корне проекта:

```dotenv
SECRET_KEY=change-me-please
FLASK_DEBUG=1

# Ключ Groq API — получить бесплатно: https://console.groq.com
GROQ_API_KEY=gsk_...
GROQ_MODEL=llama-3.3-70b-versatile

# Опционально
UNIVERSITY_NAME=ЕНУ им. Л.Н. Гумилёва
ACADEMIC_YEAR_DEFAULT=2025-2026
```

### 4. Запустить

```bash
python main.py
```

Приложение будет доступно на `http://127.0.0.1:5000`.

**По умолчанию создаётся администратор:** `admin / admin` — смените пароль после первого входа.

### Продакшен (gunicorn)

```bash
gunicorn -w 4 -b 0.0.0.0:8000 main:app
```

## Первоначальный посев дисциплин

Список дисциплин можно засеять из подготовленного JSON:

```bash
python scripts/seed_disciplines.py
```

Скрипт `scripts/extract_disciplines_from_xls.py` конвертирует учебный план (Excel) в JSON, который затем используется для посева.

## Локализация

Переключение языка — по маршруту `/set-language/<lang>` (`ru` или `kk`). Выбранный язык хранится в сессии. Все строки интерфейса вынесены в `i18n.py` (функция `t(key, lang, **kwargs)`).
